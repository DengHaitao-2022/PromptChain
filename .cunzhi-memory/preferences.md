# 用户偏好设置

- ## 用户偏好设置

1. **✔️ 生成总结性Markdown文档** - 任务完成后生成说明文档
2. **❌ 不自动生成测试脚本** - 用户会自行处理测试
3. **❌ 不自动编译** - 用户自己编译
4. **❌ 不自动运行** - 用户自己运行
- 前端页面元素的用户可见文本默认尽量使用中文，包括标题、按钮、导航、表单标签、占位提示、空状态和错误提示；仅在专有名词、协议字段、代码标识或必须保留英文时使用英文。
- 前端代码相关任务使用 Gemini CLI 时，默认优先使用 gemini-3.1-pro-preview 模型；若用户未另行指定，结合 /ui-ux-pro-max 执行。
- 用户明确要求：后续 Gemini CLI 执行前端任务时优先使用 gemini-3.1-pro-preview 模型；若该模型因容量或网络问题不可用，必须显式告知用户，不得静默切换到其他 Gemini 模型。
- 前端代码相关任务使用 Gemini CLI 时，默认优先使用 gemini-3.1-pro-preview；若调用失败，则回退使用 auto-gemini-3，并在切换时明确告知用户。
- 涉及 frontend/ 的实际编码必须由 Gemini CLI 执行，固定优先使用 gemini-3.1-pro-preview；若模型不可用，则切换为 auto-gemini-3。
- 用户在本轮明确要求：不要生成总结性 Markdown 文档；不要生成测试脚本；不要编译；不要运行；前端首页优化任务只做代码与设计修改，不额外交付总结文档。
- 用户更新了 Gemini CLI 模型偏好顺序：1) gemini-3.1-pro-preview；2) gemini-2.5-pro；3) 其他可用 Gemini 模型。若发生模型回退，必须显式告知并记录。
